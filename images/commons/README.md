# 위키미디어 공용 사진 출처

직접 찍은 사진이 없는 나무의 상세 페이지에 쓴 사진이에요. 모두 [위키미디어 공용](https://commons.wikimedia.org)의 자유 라이선스 사진이고, 웹용으로 가로 960px 크기를 받았어요. 파일은 원본 색 그대로이며 페이지에서 CSS(`filter: grayscale(100%)`)로 흑백으로 보여 줘요.

직접 찍은 사진이 생기면 `images/` 폴더에 넣고 상세 페이지의 `src`를 바꾸면 돼요. 그때 `tree-photo--external` 클래스와 출처 문구(`photo-credit`)는 지우면 돼요.
